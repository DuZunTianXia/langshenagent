The phone's chat is steadier, and SSH remote development had several long-standing bugs fixed.

Fixed
- Remote projects no longer list another program's sessions: a server left running since before an upgrade kept reading the old sessions folder; each build's daemon is now its own, and the old ones die out.
- An MCP server switched off in Settings → Customize is really off: never connected, its tools never in the context (before, they were only refused when called, their schemas in every request). In LangshenAgent's own core the switch applies to a running session at once.
- Moving the data folder no longer leaves data behind: the Claude sessions, bots, usage records and update files move with it now.
- The phone's conversation holds its pin to the bottom as answers stream, pairing draws the scan frame's sweep, and the link dials link-local IPv6 where nothing else is found.

Note: turning MCP servers off fully applies on the built-in core; with the official CLI their tools are still listed (as Claude Code itself does) and only their calls are refused.
